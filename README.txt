⚡ 雷霆战机 - Thunder Fighter  v2.0
===================================

一款网页版纵版弹幕射击游戏。
无需安装，双击即可游玩！

## 打开方式

### Windows
双击 "启动游戏.bat" 即可

### 安卓
方式一：用 Chrome 打开 index.html，菜单选择"添加到主屏幕"
方式二：直接访问 https://uooh589.github.io/thunder-fighter-game/

### 苹果
用 Safari 打开，分享按钮选择"添加到主屏幕"

## 操作

桌面端: 方向键/WASD移动 | E轰炸 | Q托管 | Esc暂停
移动端: 手指拖拽移动 | 底部按钮操作
